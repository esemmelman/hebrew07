# Hebrew Practice

Open `index.html` in a browser. Select Letters, Vowels, or Words from the list on the left. Each click chooses a new random item and grows it from tiny to large over ten seconds. The final item stays visible until another selection. Arrow keys navigate the list; Enter or Space shows another item.

Vowel marks use a dotted circle to make their position visible. Words include Hebrew vowel marks. No installation or internet connection is required.
